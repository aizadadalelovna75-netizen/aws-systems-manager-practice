# AWS Systems Manager Practice

## Тақырыбы
Amazon EC2 инстанстарында қашықтан командаларды орындау үшін
AWS Systems Manager пайдалану.

## Мақсаты
GitHub Actions арқылы AWS Systems Manager Run Command
қызметіне сұраныс жіберіп, EC2 инстансында командаларды орындау.

## Қолданылатын технологиялар
- Amazon EC2
- AWS Systems Manager
- GitHub
- GitHub Actions
- AWS CLI

## Орындалатын командалар
- hostname
- whoami
- date
- uname -a

## Күтілетін нәтиже
EC2 инстансында командалар орындалып,
олардың нәтижесі GitHub Actions журналында көрсетіледі.
